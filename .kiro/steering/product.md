# 产品：Calm Frame

**一句话**：把 19 世纪的老相框"复活"成一个会读空气的相框。手机/iPad 放在工位上，在设备端听办公室氛围，生成一幅反向安抚的复古油画/老明信片。

- 参赛：Kiroween 2026，类别 **Resurrection**（复活老式相框 + 19 世纪风景油画传统）
- 目标用户：开放式办公室里的知识工作者
- 四种氛围（mood）：`hectic`（忙乱）、`noisy`（吵闹）、`tenseQuiet`（紧绷的安静）、`drowsy`（犯困）
- 反向安抚：hectic→静水湖面，noisy→雪原/远山，tenseQuiet→开阔天空与云，drowsy→阳光窗台
- 万圣节彩蛋：极吵时画里飘过一只小幽灵；下班后（默认 19:00 后）切换 `gothicNight` 哥特夜景风格

## 不可违背的原则
1. **永不录音、永不上传音频**。只有 mood 标签（以及粗粒度特征的枚举值）离开设备。
2. AI 供应商的 API key 只存在服务器端，app 二进制里不得出现任何密钥。
3. 评委无需付费即可体验：新用户赠送免费点数（starter credits）。
4. 相框模式是"零操作"的：放下即用，切换画面用慢速淡入淡出（crossfade ≥ 3s）。

## 语气
文案温和、简短、带一点旧时代书信的味道；彩蛋可以俏皮，但不吓人。
